# Sway Keyboard Shortcuts

Modifier: `$mod` = Super/Windows key

## Applications
- `$mod+c` Terminal (current dir) | `$mod+Shift+c` New terminal
- `$mod+w` Firefox     | `$mod+f` Thunar
- `$mod+a` Slack       | `$mod+r` Renoise  | `$mod+p` App launcher
- `$mod+o` KeePassXC   | `$mod+Shift+s` Screenshot

## Window Management
- `$mod+Shift+q` Kill window        | `$mod+Shift+Alt+q` Exit Sway
- `$mod+space` Float toggle         | `$mod+Shift+space` Fullscreen
- `$mod+Shift+f` Toggle float/tile focus
- `$mod+Shift+r` Reload config      | `$mod+Ctrl+b` Border toggle

## Focus/Move (QWERTY: h/j/k/l | Colemak: m/n/e/i)
- `$mod+h/m/j/n/k/e/l/i` Focus left/down/up/right
- `$mod+Shift+h/m/j/n/k/e/l/i` Move left/down/up/right

## Workspaces
- `$mod+1-9,0` Switch to workspace 1-10
- `$mod+tab` Back & forth | `$mod+Shift+tab` Previous
- `$mod+Shift+1-9,0` Move window to workspace 1-10
- `$mod+Ctrl+1-9,0` Move window & follow to workspace 1-10

## Layout
- `$mod+b` Horizontal split | `$mod+v` Vertical split
- `$mod+Ctrl+s` Stacking    | `$mod+Ctrl+t` Toggle layout
- `$mod+Ctrl+q` Toggle split

## Resize Mode (`$mod+Ctrl+r` to enter)
- `n/o` Shrink/grow width | `e/i` Grow/shrink height
- `Enter/Escape` Exit resize mode

## Scratchpad
- `$mod+Shift+minus` Send to scratchpad
- `$mod+minus` Show/hide scratchpad

## Monitors
- `$mod+comma` Focus left | `$mod+period` Focus right

## Media (XF86 keys)
- Volume: Raise/Lower/Mute | Mic: Mute
- Playback: Play/Pause/Next/Prev | Brightness: Up/Down

## System
- `$mod+Shift+Backspace` Suspend
- `$mod+Ctrl+Backspace` Shutdown
- `$mod+Ctrl+Shift+Backspace` Reboot
- `$mod+Ctrl+l` Lock screen

## Mouse
- `$mod+Left/Right-click` Move/Resize floating window
